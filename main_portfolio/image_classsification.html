프로젝트 개요

Data & AI 수업에서 체득한 기술적 역량과 저의 음악적 전문성을 결합하여 기획한 드럼 심벌 이미지 분류기 프로젝트입니다. 입력된 심벌 이미지를 딥러닝 모델로 실시간 분석하여, 각 악기의 고유한 특성과 카테고리를 정확하게 판별해내는 AI 모델을 구현했습니다.

  • 프로젝트명: Drum Cymbal Image Classifier
  • 사용 기술: Python, Cline AI, 파이썬 기반 AI 라이브러리
  • 핵심 목표: 심벌 이미지 데이터 정리, 인공지능 모델 학습 및 실시간 판별 기능 구현

개발 과정

드럼 심벌 이미지 분류기를 직접 구현하면서, AI 모델이 시각적인 미세한 특징을 학습하여 비슷한 이미지를 구별해 낼 수 있음을 확인했습니다. 하지만 크래시(Crash), 라이드(Ride), 스플래시(Splash) 같은 심벌은 원래 청각적인 소리에 의존해 구분되는 악기이기 때문에, 순수 시각 데이터만으로는 세부 모델 분류에 한계가 있음을 깨달았습니다. 또한, 하이햇(Hi-hat) 심벌의 경우 '하이햇 스탠드'라는 주변 구조적 특징이 뒷받침되어야만 AI가 정확히 인식할 수 있다는 점을 발견하였습니다.

배운 점 & 향후 지향점:
  • 데이터 정리 및 일반화: 학습될 이미지들을 AI를 통해 수집하고 손수 분리하면서 AI 학습용 데이터를 다루는 방법을 익혔습니다.
  • 실시간 분류 모델 구현의 이해: 학습된 모델이 새로운 이미지를 입력받았을 때 정확하게 종류를 도출해내는 전체 흐름을 이해했습니다.
  • 음악적 지식의 기술적 접목: 실제 악기에 대한 이해도를 바탕으로 AI 프로젝트에 독창적인 아이디어를 녹여내는 개발 역량을 쌓았습니다.
  • 보완해야 할 점: 악기는 눈으로만 분류하기에는 한계가 많음을 이해하였으며, 향후에는 오디오 데이터를 활용한 소리 기반의 악기 분류기를 직접 제작해보고 싶다는 확장된 시야를 갖게 되었습니다.
