프로젝트 개요

수업 시간(Data&AI)에 다뤘던 과제 결과물(게임)에서 더 나아가 AI를 이용해 코드를 개선하고 기능을 향상시켜 보았습니다.

  • 게임명: geometry splash
  • 개발 배경: 수업 과제로 진행했던 기초 버전을 바탕으로, 버그 수정 및 기능 향상
  • 주요 특징: 직접 플레이 하면서 겪은 버그를 토대로 다시 프롬프트를 작성하고 수정함

개발 과정

과제를 진행할 때는 '도형 맞추기 게임을 만들어달라'는 단순하고 광범위한 프롬프트만을 사용했기에, 결과물의 디테일을 살리는데 한계가 있었습니다. 이를 바탕으로 수정본 에서는 원하는 기능과 UI 요소를 구체적으로 명시하고, 버그에 대한 원인을 파악하여 수정하였습니다.

개선 사항 & 배운 점:
  • 버그 수정 및 기능 향상: 코드를 다른 AI에게 학습시켜 원인이 될 만한 부분을 파악하였습니다.
    - 프레임 레이트가 아닌 실제 시간 기준 사용
    - 마름모와 육각형이 구분되지 않은 버그 수정
    - 정답과 중복되는 도형 생성하지 않게 수정
    - 잘못된 도형 선택되지 않도록 수정
    - 도형이 화면 밖으로 나가지 않도록 사각형 틀 사용
    - 도형이 회전하도록 설정
    - 기타 사소한 부분 개선
  • AI 의존성에 대한 경각심: AI가 생성한 코드의 버그 원인을 스스로 파악하기 어려워 다른 AI에 재차 의존하는 과정을 겪으며, 개발자로서의 기본적 코드 분석 역량이 얼마나 중요한지 깊이 깨달았습니다. 이를 계기로 AI 도구에 전적으로 의존하기보다, 저의 기술적 역량을 탄탄히 키워 문제를 주도적으로 해결하는 개발자로 성장하겠다는 다짐을 하게 되었습니다.
